# Online Exam System

A simple Online Exam System built using HTML, CSS, and JavaScript.

## Features

- Student name entry
- 5 multiple-choice questions
- 5-minute countdown timer
- Automatic score calculation
- Percentage calculation
- Pass/Fail result
- Restart exam option
- Responsive basic design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Files

- `index.html` - Main exam page
- `style.css` - Styling
- `script.js` - Timer and result calculation

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Enter a student name.
4. Click **Start Exam**.
5. Answer the questions and submit the exam.
